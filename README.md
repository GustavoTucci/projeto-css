# Projeto CSS - Atividade 01

Página web desenvolvida para praticar conceitos de CSS Flexbox durante a aula 7 do curso de Front-End.

## Sobre o projeto

O projeto apresenta uma área responsiva com 20 cartões coloridos, cada um representando uma tecnologia ou ferramenta do desenvolvimento web. Os cartões utilizam diferentes configurações de Flexbox para demonstrar crescimento, redução, ordem, espaçamento e tamanho base dos elementos.

## Tecnologias utilizadas

- HTML5
- CSS3
- Flexbox

## Estrutura do projeto

```text
projeto-css/
├── index.html
├── style.css
└── README.md
```

## Como executar

1. Clone ou baixe este repositório.
2. Abra o arquivo `index.html` diretamente no navegador.

Também é possível utilizar a extensão **Live Server** no VS Code para visualizar as alterações em tempo real.

## Conceitos praticados

- Estrutura semântica com HTML
- Variáveis CSS
- Gradientes e sombras
- Layout com `display: flex`
- Quebra de linha com `flex-wrap`
- Alinhamento com `justify-content`, `align-items` e `align-content`
- Controle individual com `order`, `flex-grow`, `flex-shrink` e `flex-basis`
- Responsividade com media queries
- Efeitos de interação com `:hover`

## Objetivo

Praticar a criação de layouts flexíveis e responsivos, observando como diferentes propriedades do Flexbox influenciam a organização dos elementos na página.
